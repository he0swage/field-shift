# Field Shift

## Run the app locally

```bash
# terminal 1 — API (Express, port 5001)
cd backend
npm install
npm run dev

# terminal 2 — web app (React + Vite, port 5173)
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. Details are in `backend/README.md` (routes, CORS, data) and
`frontend/README.md` (structure, design, i18n).
