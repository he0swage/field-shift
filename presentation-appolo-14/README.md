# Field Shift · présentation

Ouvrir `index.html` dans Chrome ou Edge (double-clic, aucun serveur ni internet nécessaire).

- **Suivant** : flèche droite, espace ou clic · **Retour** : flèche gauche ou clic à gauche de l'écran
- **Plein écran** : touche F · **Aller à une slide** : `index.html#4`

## Fichiers

- `index.html` : le contenu des 9 slides
- `style.css` : palette (variables en haut du fichier), police Poppins, mise en page
- `script.js` : la caméra du zoom (Terre → région → téléphone) et la navigation
- `data.js` : **toutes les valeurs affichées**. Ce sont des valeurs d'exemple, à remplacer par les chiffres confirmés.
- `img/` : Terre (NASA Blue Marble), carte de la région, champs, étoiles
- `fonts/` : Poppins (licence SIL Open Font License)
