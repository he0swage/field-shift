Put the Montaser Arabic font files here (Arabic UI font):
  MontaserArabic-Regular.woff2 (or .ttf)
  MontaserArabic-Medium.woff2
  MontaserArabic-SemiBold.woff2
  MontaserArabic-Bold.woff2
If the font is installed on the computer it is used automatically.
Check the font licence allows web use before committing the files.
Until then the site falls back to Noto Sans Arabic (Google Fonts).
